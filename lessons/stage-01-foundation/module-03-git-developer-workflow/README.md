# Module 3 - Git + Developer Workflow

> **Tóm tắt:** Git từ con số không tới làm việc nhóm: cài đặt, commit, remote và GitHub, nhánh, merge/rebase, pull request, CI, giải xung đột, cứu dữ liệu, tìm lỗi bằng `git bisect`, quy ước commit và xử lý sự cố lộ bí mật.

> **Thứ tự đọc khuyên dùng khi mới học Git:** 3.1 → 3.2 → 3.4 → 3.5 → 3.6 → 3.7 → **3.3** → 3.8 trở đi. Bài 3.3 (an toàn và cứu dữ liệu) dùng nhánh, `push` và `rebase` nên dễ hiểu hơn sau khi học 3.4–3.7.
