#### Bài 1 — Máy tính đơn giản (Dễ, 15 điểm)

Viết hàm `Calculate(double a, double b, char op)` nhận hai số và một toán tử (`+`, `-`, `*`, `/`), trả về kết quả.

```csharp
// Code khởi đầu
double Calculate(double a, double b, char op)
{
    // TODO: dùng switch expression xử lý 4 phép tính
    // Chia cho 0: trả về double.NaN
    // Toán tử khác: ném ArgumentException
    throw new NotImplementedException();
}

Console.WriteLine(Calculate(10, 3, '+'));   // 13
Console.WriteLine(Calculate(10, 3, '/'));   // 3,3333333333333335 (máy vùng Việt Nam)
Console.WriteLine(Calculate(10, 0, '/'));   // NaN
```

**Tiêu chí chấm:**

- (5 điểm) Bốn phép tính cho đúng kết quả như ba dòng mẫu.
- (5 điểm) Chia cho 0 trả về `NaN`. Lưu ý: không xử lý gì thì `10.0 / 0` **không** ném lỗi mà trả về `∞` (`Infinity`); chỉ phép chia **số nguyên** cho 0 mới ném `DivideByZeroException`. Đề yêu cầu `NaN` để kết quả "không phải số" hiện rõ.
- (5 điểm) Toán tử khác (ví dụ `'%'`) ném `ArgumentException` có thông báo nói rõ toán tử nào.

<details>
<summary><strong>Lời giải — Bài 1</strong></summary>

```csharp
double Calculate(double a, double b, char op) => op switch
{
    '+' => a + b,
    '-' => a - b,
    '*' => a * b,
    '/' when b == 0 => double.NaN,
    '/' => a / b,
    _ => throw new ArgumentException($"Toán tử không hỗ trợ: {op}", nameof(op)),
};
```

`'/' when b == 0` là nhánh có thêm điều kiện: chỉ khớp khi toán tử là `/` **và** `b` bằng 0. Nhánh này phải đứng trước nhánh `'/'` thường, vì nhánh đầu tiên khớp sẽ thắng. Gọi `Calculate(10, 3, '%')` ném `System.ArgumentException: Toán tử không hỗ trợ: % (Parameter 'op')`.

</details>

#### Bài 2 — Phân tích danh sách điểm (Trung bình, 20 điểm)

Viết hàm `AnalyzeScores(List<int> scores)` in ra điểm trung bình, điểm cao nhất, thấp nhất và số học viên đạt (từ 50 điểm trở lên). Chỉ dùng `foreach`, không dùng LINQ, để luyện vòng lặp.

```csharp
var scores = new List<int> { 45, 72, 88, 35, 60, 91, 48, 77 };
AnalyzeScores(scores);
AnalyzeScores(new List<int>());
```

Output mong đợi (máy đặt vùng Việt Nam):

```text
Trung bình: 64,5
Cao nhất: 91 | Thấp nhất: 35
Số đạt: 5/8 (62,5%)
Danh sách rỗng!
```

**Tiêu chí chấm:**

- (8 điểm) Ba dòng đầu đúng như mẫu với danh sách trên.
- (4 điểm) Trung bình là `64,5` chứ không phải `64`: phép chia không bị làm tròn thành số nguyên.
- (4 điểm) Danh sách rỗng in `Danh sách rỗng!`, không ném lỗi.
- (4 điểm) Ngưỡng 50 là hằng số có tên (`const int PassMark = 50;`), và điểm đúng 50 được tính là đạt.

<details>
<summary><strong>Lời giải — Bài 2</strong></summary>

```csharp
void AnalyzeScores(List<int> scores)
{
    if (scores.Count == 0)
    {
        Console.WriteLine("Danh sách rỗng!");
        return;
    }

    const int PassMark = 50;
    int sum = 0, max = scores[0], min = scores[0], passed = 0;
    foreach (var s in scores)
    {
        sum += s;
        if (s > max) max = s;
        if (s < min) min = s;
        if (s >= PassMark) passed++;
    }

    double average = (double)sum / scores.Count;   // ép sang double để không chia nguyên
    Console.WriteLine($"Trung bình: {average}");
    Console.WriteLine($"Cao nhất: {max} | Thấp nhất: {min}");
    Console.WriteLine($"Số đạt: {passed}/{scores.Count} ({(double)passed / scores.Count:P1})");
}
```

Bẫy chính: `sum / scores.Count` với hai số `int` là **chia nguyên**, cho `64` (516 / 8 = 64 dư 4). `(double)sum` đổi một vế sang `double` trước khi chia. `:P1` định dạng phần trăm với một chữ số thập phân.

`max` và `min` khởi tạo bằng `scores[0]` chứ không phải bằng 0: nếu mọi điểm đều âm (dữ liệu lỗi) thì `max = 0` sẽ sai. Vì vậy phải kiểm tra danh sách rỗng **trước**.

</details>

#### Bài 3 — Đếm tần suất từ (Trung bình - Khá, 20 điểm)

Viết hàm `CountWordFrequency(string sentence)` trả về `Dictionary<string, int>`: mỗi từ (viết thường) xuất hiện bao nhiêu lần.

```csharp
var frequency = CountWordFrequency("crm giúp quản lý khách hàng crm rất hữu ích");
foreach (var pair in frequency)
    Console.WriteLine($"{pair.Key}: {pair.Value} lần");
```

Output mong đợi bắt đầu bằng:

```text
crm: 2 lần
giúp: 1 lần
quản: 1 lần
```

**Tiêu chí chấm:**

- (8 điểm) `crm` đếm được 2, mọi từ khác đếm được 1.
- (4 điểm) Không phân biệt hoa thường: `"CRM crm"` cho `crm: 2`.
- (4 điểm) Nhiều dấu cách liên tiếp hoặc dấu cách ở hai đầu không sinh ra "từ rỗng".
- (4 điểm) Dùng `TryGetValue` (một lần tra) thay cho cặp `ContainsKey` rồi `[key]`.

<details>
<summary><strong>Lời giải — Bài 3</strong></summary>

```csharp
Dictionary<string, int> CountWordFrequency(string sentence)
{
    var result = new Dictionary<string, int>();
    string[] words = sentence.ToLower().Split(' ', StringSplitOptions.RemoveEmptyEntries);

    foreach (var word in words)
    {
        if (result.TryGetValue(word, out int count))
            result[word] = count + 1;
        else
            result[word] = 1;
    }

    return result;
}
```

`StringSplitOptions.RemoveEmptyEntries` bỏ các phần rỗng sinh ra khi có hai dấu cách liền nhau. Thiếu nó, `"crm  crm"` cho ra một "từ" rỗng `""`.

**Mở rộng (không chấm):** với câu có dấu câu, `"CRM, crm"` hiện cho hai từ khác nhau là `crm,` và `crm`. Muốn gộp thì tách theo cả dấu câu: `Split(new[] { ' ', ',', '.', '!', '?' }, StringSplitOptions.RemoveEmptyEntries)`.

Thứ tự in ra trùng thứ tự từ xuất hiện lần đầu, nhưng đó là chi tiết cài đặt của `Dictionary` hiện tại, tài liệu không bảo đảm. Cần thứ tự cố định thì sắp xếp trước khi in.

</details>

#### Bài 4 — Quản lý lead CRM mini (Nâng cao, 25 điểm)

Viết chương trình quản lý lead (khách hàng tiềm năng) dùng một `Dictionary<string, decimal>` lưu tên lead và doanh thu ước tính, với bốn hàm:

| Hàm | Việc làm |
|---|---|
| `AddLead(string name, decimal revenue)` | Thêm lead. Tên rỗng, doanh thu âm, hoặc tên đã có: in thông báo và **không** ghi đè |
| `ListAllLeads()` | In bảng tên, doanh thu, phân loại |
| `TotalRevenue()` | Trả về tổng doanh thu của mọi lead |
| `FilterByTier(string tier)` | Trả về danh sách tên lead thuộc phân loại đó |

Phân loại: **Hot** từ 100.000.000 trở lên, **Warm** từ 20.000.000 trở lên, **Cold** dưới 20.000.000.

Dữ liệu thử:

```csharp
AddLead("Công ty Minh Phát", 150_000_000m);
AddLead("Startup GreenTech", 35_000_000m);
AddLead("Hộ kinh doanh Lan", 8_000_000m);
AddLead("Tập đoàn Bắc Nam", 500_000_000m);
AddLead("Cửa hàng Thuận Phát", 12_000_000m);
AddLead("Startup GreenTech", 40_000_000m);    // trùng tên
```

**Tiêu chí chấm:**

- (8 điểm) Đủ bốn hàm, đúng tên như bảng; `TotalRevenue()` trả `705.000.000` với dữ liệu thử.
- (6 điểm) Phân loại đúng ở cả hai mốc: 100.000.000 là Hot, 20.000.000 là Warm. Hai ngưỡng là hằng số có tên, không viết số trần trong code.
- (5 điểm) Thêm trùng tên in thông báo và giữ nguyên doanh thu cũ (35.000.000).
- (3 điểm) `FilterByTier("Cold")` trả về đúng hai lead Hộ kinh doanh Lan và Cửa hàng Thuận Phát.
- (3 điểm) Bảng in ra thẳng cột.

<details>
<summary><strong>Lời giải — Bài 4</strong></summary>

```csharp
const decimal HotThreshold = 100_000_000m;
const decimal WarmThreshold = 20_000_000m;

var leads = new Dictionary<string, decimal>();

AddLead("Công ty Minh Phát", 150_000_000m);
AddLead("Startup GreenTech", 35_000_000m);
AddLead("Hộ kinh doanh Lan", 8_000_000m);
AddLead("Tập đoàn Bắc Nam", 500_000_000m);
AddLead("Cửa hàng Thuận Phát", 12_000_000m);
AddLead("Startup GreenTech", 40_000_000m);    // trùng tên: báo, không ghi đè

ListAllLeads();
Console.WriteLine($"Tổng doanh thu ước tính: {TotalRevenue():N0}");
Console.WriteLine($"Lead Cold: {string.Join(", ", FilterByTier("Cold"))}");

void AddLead(string name, decimal revenue)
{
    if (string.IsNullOrWhiteSpace(name))
    {
        Console.WriteLine("Tên lead không được để trống");
        return;
    }
    if (revenue < 0)
    {
        Console.WriteLine($"Doanh thu của {name} không được âm");
        return;
    }
    if (!leads.TryAdd(name, revenue))            // TryAdd trả false nếu khóa đã có
        Console.WriteLine($"Lead '{name}' đã tồn tại, bỏ qua");
}

string Classify(decimal revenue) => revenue switch
{
    >= HotThreshold  => "Hot",
    >= WarmThreshold => "Warm",
    _                => "Cold",
};

void ListAllLeads()
{
    Console.WriteLine($"{"Tên lead",-22} {"Doanh thu",15} {"Loại",-5}");
    foreach (var (name, revenue) in leads)
        Console.WriteLine($"{name,-22} {revenue,15:N0} {Classify(revenue),-5}");
}

decimal TotalRevenue()
{
    decimal total = 0;
    foreach (var revenue in leads.Values) total += revenue;
    return total;
}

List<string> FilterByTier(string tier)
{
    var result = new List<string>();
    foreach (var (name, revenue) in leads)
        if (Classify(revenue) == tier) result.Add(name);
    return result;
}
```

Output chạy thật trên .NET 10 (máy đặt vùng Việt Nam):

```text
Lead 'Startup GreenTech' đã tồn tại, bỏ qua
Tên lead                     Doanh thu Loại
Công ty Minh Phát          150.000.000 Hot
Startup GreenTech           35.000.000 Warm
Hộ kinh doanh Lan            8.000.000 Cold
Tập đoàn Bắc Nam           500.000.000 Hot
Cửa hàng Thuận Phát         12.000.000 Cold
Tổng doanh thu ước tính: 705.000.000
Lead Cold: Hộ kinh doanh Lan, Cửa hàng Thuận Phát
```

Vài điểm đáng chú ý:

- `{name,-22}` căn trái trong 22 ký tự, `{revenue,15:N0}` căn phải trong 15 ký tự có dấu phân cách nghìn: đó là cách in bảng thẳng cột.
- `foreach (var (name, revenue) in leads)` tách mỗi cặp khóa, giá trị của `Dictionary` ra hai biến.
- Dùng `leads[name] = revenue` thay cho `TryAdd` là lỗi hay gặp: trùng tên sẽ **ghi đè** âm thầm, đúng cái bẫy ở [bài 1.2](1.2-conditions.md).

**Mở rộng (không chấm):** in danh sách lead theo doanh thu giảm dần bằng `leads.OrderByDescending(l => l.Value)`.

</details>
