# Giai đoạn 1 — Foundation: tư duy lập trình, nền tảng CS và Git workflow

> **Tóm tắt:** Giai đoạn nền của lộ trình .NET Backend, gồm 3 module: Module 1 - Programming Logic (biến và kiểu dữ liệu, điều kiện, vòng lặp, hàm, mảng và list, tư duy giải quyết vấn đề, cấu trúc dữ liệu và Big O), Module 2 - Computer Science Basics (kiến thức khoa học máy tính ứng dụng cho backend: HTTP/REST/JSON, runtime và hệ sinh thái .NET), Module 3 - Git + Developer Workflow (quy trình Git, branching và code review). Đây là phần cần nắm trước khi bước vào các module C# chuyên sâu.
