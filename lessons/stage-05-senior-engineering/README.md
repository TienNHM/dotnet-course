# Giai đoạn 5 — Senior Engineering: Clean Architecture, hệ phân tán và microservices

> **Tóm tắt:** Giai đoạn cấp senior/architect, gồm 4 module: Module 16 - Clean Architecture (kèm DDD tactical patterns), Module 17 - Distributed Systems (nhất quán dữ liệu, messaging, xử lý lỗi phân tán), Module 18 - Microservices (phân rã dịch vụ, gateway, giao tiếp giữa service), Module 19 - Performance Engineering (đo trước/sau, BenchmarkDotNet, profiling, distributed lock, chiến lược scaling). Khép lại bằng Final Project - Enterprise CRM/ERP, sản phẩm portfolio hoàn chỉnh.

> [!NOTE]
> **Phần nâng cao, không bắt buộc.** Phần chính của khóa học kết thúc ở [Project 3 — Production CRM Platform](../stage-04-database-production/project-03-production-crm-platform.md). Học giai đoạn này sau khi đã làm xong Project 3: các pattern ở đây giải quyết vấn đề của hệ thống lớn, nên chỉ có ý nghĩa khi bạn đã gặp những vấn đề đó.
